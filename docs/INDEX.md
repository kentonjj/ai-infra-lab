# 文档索引

## 规则与流程

| 文件 | 内容 |
|---|---|
| AGENTS.md（根目录） | AI 编码工具的合并门禁，冲突时以此为准 |
| RULES.md | 学习铁律 8 条、4 条红线、每周日 5 问审计 |
| failures.md | 失败日志，每周至少一条 |
| ai-log.md | AI 使用日志：帮助、局限、验证方式 |

## 环境与数据

| 文件 | 内容 |
|---|---|
| env.md | 环境矩阵：机器、GPU、驱动、Python、引擎版本 |
| ../bench/results/ | 基准结果 JSON（matmul 与 LLM 压测） |
| ../experiments/ | 实验记录，每个含假设/配置/结果/结论 |

写作约定：结论在前，数据在后；每个设计都要有「失败路径」一节；
每个性能结论都要有对照实验。
